figure 3 · the attestation

37 bytes that tie a burn to the fees that paid for it.

after every PYRE buyback-and-burn the treasury sends a zero-value transaction to itself. its calldata is a fixed prefix, a version byte and a sha256 of the ids of the fee-share entries consumed.

magic
ascii "P" "Y" "R" "E". marks the tx as a pyre attestation.

01
version
scheme v1. any other value is not an attestation.
32 bytes
sha256( sorted ids, joined by "," )
fee hash
the ids of the 25% fee-share entries the burn consumed, sorted, comma-joined, hashed. order-independent; any change to the set changes the hash.
